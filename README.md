# Photogrammetry 3D Reconstruction

A web-based viewer for 3D models created using photogrammetry.

## Live Demo

https://selinkshengova.github.io/Photogrammetry-3D-Website/

## Technologies

- HTML
- CSS
- JavaScript
- 3D model visualization
- Photogrammetry workflow

## Process

1. Capture object photos
2. Generate 3D reconstruction
3. Optimize the model
4. Display it on the web
